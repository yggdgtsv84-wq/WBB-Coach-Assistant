# Cloud setup
1. Create a free Supabase project.
2. Open SQL Editor and run `supabase_schema.sql`.
3. Open Project Settings > API.
4. Copy the Project URL and public/anon key into `config.js`.
5. Never use the service_role/secret key in the website.
6. Upload the files to a GitHub repository.
7. Enable GitHub Pages from Settings > Pages, publishing from the main branch/root.
8. Open the published HTTPS address on your iPhone/iPad.
9. Create one coach account and use the same account on every device.
10. Add/edit your two teams and players.

Game workflow:
- Choose team.
- Start Game.
- Enter opposition.
- Track 1/2/3 points, fouls (max 5), and substitutions.
- Enter opposition final score.
- Press END / SAVE GAME.
- The completed game is stored in the cloud.
- Game History shows team-specific results and individual game stats.
- Season totals are calculated from saved games.
